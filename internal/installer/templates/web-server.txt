Your own web server provides HTTPS for {{.Domain}} and must run on this server, since the
site answers on {{.Addr}} alone. During the restart after an update it shows its own
error page, unless it can hold requests until the site answers again. A web server in a
container needs this server's own network, such as network_mode: host, since a
container's loopback address is its own. The lines below send {{.Domain}} to the site with
the visitor's host, client address and scheme, and a body limit as large as the largest
upload the site takes: a file of the {{.UploadMB}} MB {{.UploadSetting}} allows or a
theme of {{.ThemeMB}} MB, each with {{.EnvelopeKB}} KB of form framing around it.
